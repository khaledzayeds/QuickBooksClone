# Manual QA Checklist - Zayed Offline ERP v1

1. Start app from the release folder.
2. Confirm `Zayed.exe` opens without manually starting the API.
3. Create a company.
4. Complete setup.
5. Create or confirm admin credentials and change password if required.
6. Login.
7. Create a customer.
8. Create a vendor.
9. Create an inventory item.
10. Create a sales receipt.
11. Create an invoice.
12. Receive customer payment.
13. Create a purchase order.
14. Receive inventory from the purchase order.
15. Create bill from receipt.
16. Pay vendor.
17. Run Trial Balance.
18. Run Profit and Loss.
19. Run Balance Sheet.
20. Create backup.
21. Create another invoice.
22. Restore the backup.
23. Verify the second invoice disappears and the earlier data remains.
24. Print invoice.
25. Print sales receipt.
26. Switch language to Arabic.
27. Switch language to English.
28. Logout.
29. Restart app.
30. Reopen company.
31. Login again.
32. Confirm no debug or playground screens are visible in production navigation.
33. Record any failed item in `COMMERCIAL_RELEASE_CHECKLIST.md`.
